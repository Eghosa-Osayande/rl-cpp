# Comparison of Planning and Control Action Spaces for Reinforcement Learning-Based Online Coverage

## Abstract
This work studies how action-space abstraction affects reinforcement-learning-based online coverage path planning (CPP). In particular, it compares a control-oriented action space, a=(v,ω), with a planning-oriented path-primitive space, a=(Δθ,r), within a common learning framework while keeping the sensing, mapping, observations, network architecture, reward function, and learning algorithm unchanged. Both formulations achieved broadly comparable coverage and collision performance, with the planning formulation requiring about five times fewer policy decisions but exhibiting higher overlap and greater variability in path efficiency.
